Supported subset & limitations
Supported
  • Block mappings and block sequences, nested by indentation
  • Flow collections written on one line: [a, b], {a: 1, b: c}
  • Plain, single-quoted and double-quoted scalars, with \n, \t, \uXXXX escapes
  • Integers (decimal, 0x, 0o, 0b, legacy 0755) and floats (1e3, .5, .inf, .nan)
  • true/false (also True/TRUE), null, ~, empty value
  • Underscore digit separators written between digits (1_000 → 1000), resolved exactly as js-yaml does
  • # comments, blank lines, --- and ... document markers
  • Compact nesting: - key: value, a sequence written directly under its key
Rejected with an explicit error (never guessed)
  • Anchors &a / aliases *a / merge keys <<:
  • Tags !!str, !custom, directives %YAML, complex keys ? key
  • Block scalars | and >
  • Multi-line plain scalars and multi-line flow collections
  • Tab indentation, duplicate keys, unterminated quotes, malformed indentation
Notes
  • yes/no/on/off stay strings (YAML 1.2 core schema).
  • Dates and timestamps stay strings; they are not converted to Date objects.
  • Multiple documents convert to a JSON array; the status line says how many.
  • Nothing leaves this page: parsing and serialization run locally.
Runs offline. Conversions are done locally and stay on this device.
